# 起源

### NotebookLM

去年谷歌的NotebookLM大火，我也是持续地用了一个月，考完期末后就没再用了。直到三月份有一天在小红书刷到一个消息，就是NotebookLM出了个新功能Cinematic。这是Video Overview的一个选项，可以生成电影感的视频。当时想着终于有机会免费生成高质量视频了，兴冲冲打开网站却发现这是付费用户才有的功能。

本来想着用Cinematic做视频估计能在抖音轻松涨粉赚点零花钱，没想到免费用户没access。来都来了，尘封的抖音也已经打开、登录完了，不如就用Video Overview生成点视频发发。最近比较火的就是OpenClaw了，我让NLM去网上搜了一些资料，然后根据这些网站的内容生成视频。可惜这第一个视频只有几百浏览，一个赞都没有，只有收藏，平均观看时间貌似不到6秒。好吧，看来Openclaw这个话题还不够接地气，而且这Video Overview太枯燥太像网课了。两天之后又让NLM搜集量子力学、平行时空那些网站，然后做视频，这次浏览量和点赞都上来了，不过不是太多。NotebookLM生成的视频还是挺不适合在抖音发的，完全就是反面。虽然这个量子力学的视频的赞数与浏览量的比很高，但是还是只有五百多浏览。

### Youtube

第一个视频是在3月9日发的，第二个视频是在3月11日发的。同样在11日，发完第二条视频后我彻底放弃用NLM，但我对抖音的执念慢慢变深。那天晚上，我发了6条视频。这六条都是从Youtube上下载的，直接搬运。Youtube的第一条视频就很快引来很多流量，达到一万播放三百多点赞。这是一个非常简单的物理实验，和运动的分解有关，看那个教室应该是斯坦福的。这6条视频中同样比较火的还有丝滑连招集锦，这是偏娱乐向的，还有就是李小龙的功夫集锦。而其他3条则不是太火，因为讲的内容相对较深、配乐配音都不好，观众不明所以。这6条都是Youtube上10k+乃至100k+的火爆短视频。

我发现从油管搬运火爆的视频是个不错的策略，后来我慢慢发现，有很多高质量的Youtube短视频都有比较长的英文配音，但直接搬运的话中国观众根本听不懂。于是只能筛选那种视频非常直观或者具有视觉冲击力的，以及容易看懂的，但这些视频比较少。我就想有没有工具能把英文视频转成中文配音和字幕呢？然后我找到了[Linly-dubbing](https://github.com/Kedreamix/Linly-Dubbing)。

可是这个项目是vibe coding的，下载下来后到处是bug，不能直接用。因为它是基于[Youdub](https://github.com/liuzhao1225/YouDub-webui)的，而后者的star数甚至更高。所以我又下载了后者，然后我发现其实linly-dubbing并没有什么明显的改进。youdub也很难用。于是我又用回linly-dubbing，费尽力气调试好了。这个十几G的项目属实罕见，但是这个功能是我需要的，没办法。

我用这个项目翻译了几条视频，一个是外国版的鸡汤哲理故事，一个是自动地板新技术，还有一个8分钟的deepseek v4长视频，最后是费曼的讲话。鸡汤哲理故事赞播比很高，但流量不多，而自动地板那条视频达到了接近三十万的播放量，800+赞。后面两条两分钟以上的视频却没什么人看。费曼的讲话我只加了中文字幕，没改成中文配音。

与此同时我也保持搬运英文原视频，这包括两条C罗的播客。C罗播客赞播比挺高的，可浏览量只有几百。可是再后来继续搬运视频的时候，抖音显示说我不止一次发表低质量或非原创视频，给我限流了，我就止住了盗视频。

### Seedance And etc.

我又想起文生视频的事，我去找各种文生视频的平台，包括Google Veo,Flow，以及其他各种乱七八糟的。可是生成质量都不好，而且时长只有八秒，免费试用只有一两次。生成视频确实费算力。于是我又打开了尘封已久的seedance，在它刚发布的时候我就已经找到官网，可是官网显示暂时还不支持，要过几天。现在打开，虽然有积分送，但是太少了，于是我买了一个月的套餐。生成了抖音比较多的那种口播视频，讲大道理那种。然后找了个思路比较创新的文章，关于刘邦的，让他读，分成很多段视频生成。最后效果不怎么好。几百播放但没什么赞。我就想生成长一点的视频，于是我就开始用agent模式。受小红书的视频的启发（爱因斯坦穿越到现代被绑架，在绑匪车上通过各种方式计算行驶距离），我写了个牛顿穿越到中国高中上学的脚本。agent模式很烧token，一个下午把一个月的积分用光了，只生成了片段，没有最终视频。片段视频也非常不好。

无聊之际我开始刷抖音，看看那些高赞都是什么样的视频。我发现有那种像PPT一样的视频，但是动态效果多一点，也得了很多赞。于是我又去找这个类型的ai网站，[colossyan](https://www.colossyan.com)是非常不错的，缺点是讲解得不好。怎么说呢，这个网站是非常优秀的，但它的用途不是这个，它自己的目标都不是短视频。这个做的是网课或者产品介绍、公司介绍之类比较专业的东西。用来解释专业知识的话，讲解内容又不够详细，让抖音用户很难跟上。

### 剪映

我还注意到有那种很多素材片段拼起来的视频，每个素材和讲稿说到的那个关键词有一点联系，又和整个视频没什么关联，这种文章也很火。发现这是抖音的剪映就能做到的。发了三条视频，要么是几百播放量没赞，要么是赞播比高但播放量很少。

# 创建 WordRhythm 项目

### 纯文字流视频

经过摸索，我发现创作视频还是不适合我，不适合现在的我。这时我又想起那种文字瀑布流的视频，还有知乎五年前就有的回答转视频的功能，也是转成纯文字视频。其实不过是花样字体各种颜色和字号再用不同字号和颜色作强调，然后一个接一个短句用不同特效蹦出来。

这个看起来是很典型的能用脚本直接自动化制作的东西。用 `moviepy`这个python库，是可以实现这个功能的，做出来的效果挺不错。但是真的做的时候发现没那么简单，那就是断句的问题，断的不够完美。即便用`jieba`库（我没用）也做不到完全正常的断句。因为断句需要语义理解。短句内的关键词用加粗加大和对比色来标记突出，其实也需要语义理解。纯靠编程效果不好，又不可能为了解决这个断句的问题专门搞个机器学习模型。所以我选择把讲稿发给deepseek让它断句并格式化输出。配音的话用的是XTTS，不过遇到了很多困难，这些留到后面说。

*WordRhythm* 这个名字就是这时起的。

### Manim数学动画

后来看到，现在抖音上居然也有不少3blue1brown风格的数学视频了。虽然它们要么是选定一个听起来很牛的主题比如钱学森弹道然后让各种相关的看起来很高级很复杂的公式以0.x秒/条的速度闪过并配上震撼音乐，要么是画一些微积分三角函数圆锥曲线等等的动画加上神秘高级的音乐仿佛在临摹数学秘籍，反正都是一堆人在评论区嗨地飞起，但是它们的赞数确实不低。我觉得把[Manim](https://www.manim.community/)集成到WordRhythm里是个不错的选择。而且刚好找了个高中答疑助教的兼职，视频答疑每题赚15块钱不管是什么题，要是用Manim岂不是爽爆。
